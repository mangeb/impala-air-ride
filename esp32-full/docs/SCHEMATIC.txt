POWER SUPPLY
============
    Car 12V Battery
         |
         +--[Fuse 15A]--+-- 12V to Relay Module (for solenoids & pumps)
         |              |
         +--[Fuse 5A]---+-- 12V to Voltage Regulator
                        |
                   [LM2596 Buck Converter]  <-- Use buck converter, NOT 7805
                        |                       (ESP32-S3 needs clean 5V/3.3V)
                       5V --> ESP32-S3 VIN
                        |
                       GND --> ESP32-S3 GND

    NOTE: ESP32-S3 has built-in 3.3V regulator. Feed 5V to VIN pin.


ESP32-S3 DEVKIT PINOUT
======================
ESP32-S3 has built-in WiFi + native USB - no shield needed!
IMPORTANT: Only use ADC1 pins for analog (ADC2 conflicts with WiFi)

                       ESP32-S3 DevKit
    +--------------------------------------------------+
    |                     [USB]                        |
    |                                                  |
    | 3V3                                        GND   |
    | 3V3                                        GPIO48 --> Pump 2
    | RST                                        GPIO47 --> Pump 1
    | GPIO4  (ADC1_CH3) <-- RL Pressure          GPIO21 --> RR Deflate
    | GPIO5  (ADC1_CH4) <-- RR Pressure          GPIO14  |
    | GPIO6  --> FL Inflate                      GPIO13  |
    | GPIO7  --> FL Deflate                      GPIO12  |
    | GPIO15 --> FR Inflate                      GPIO11  |
    | GPIO16 --> FR Deflate                      GPIO10  |
    | GPIO17 --> RL Inflate                      GPIO9   |
    | GPIO18 --> RL Deflate                      GPIO46  |
    | GPIO8  --> RR Inflate                      GPIO3  (ADC1_CH2) <-- FR Pressure
    | GND                                        GPIO2  (ADC1_CH1) <-- FL Pressure
    | VIN <-- 5V                                 GPIO1  (ADC1_CH0) <-- Tank Pressure
    +--------------------------------------------------+

    NOTE: GPIO 19/20 reserved for USB D-/D+ (native USB)
          GPIO 0 is boot button - avoid for I/O

    Pin Assignment Summary:
    -----------------------
    ANALOG (ADC1 only - compatible with WiFi):
      GPIO1  (ADC1_CH0):  Tank Pressure
      GPIO2  (ADC1_CH1):  Front Left Pressure
      GPIO3  (ADC1_CH2):  Front Right Pressure
      GPIO4  (ADC1_CH3):  Rear Left Pressure
      GPIO5  (ADC1_CH4):  Rear Right Pressure

    DIGITAL (Solenoids):
      GPIO6:  FL Inflate     GPIO7:  FL Deflate
      GPIO15: FR Inflate     GPIO16: FR Deflate
      GPIO17: RL Inflate     GPIO18: RL Deflate
      GPIO8:  RR Inflate     GPIO21: RR Deflate

    DIGITAL (Pumps):
      GPIO47: Pump 1
      GPIO48: Pump 2


VDO PRESSURE SENSOR WIRING (x5 sensors)
=======================================
IMPORTANT: ESP32-S3 uses 3.3V reference, not 5V!
Use 3.3V from ESP32-S3 for the voltage divider.

           +3.3V (ESP32-S3 3V3 pin)
            |
            |
           [R_ref]  <-- 100 ohm 1/4W resistor
            |
            +--------> To ESP32-S3 ADC1 Pin (GPIO 1-5)
            |
         [VDO Sensor]  <-- Variable resistance 10-180 ohm
            |              (10 ohm = 0 PSI, 180 ohm = 150 PSI)
            |
           GND


VOLTAGE DIVIDER CALCULATIONS (3.3V):
------------------------------------
At 0 PSI (10 ohm):    V = 3.3V x 10/(100+10)   = 0.30V  (ADC: ~372)
At 75 PSI (95 ohm):   V = 3.3V x 95/(100+95)   = 1.61V  (ADC: ~1996)
At 150 PSI (180 ohm): V = 3.3V x 180/(100+180) = 2.12V  (ADC: ~2630)

ESP32-S3 ADC is 12-bit (0-4095) with 3.3V reference


COMPLETE SENSOR CIRCUIT (x5)
============================

    +3.3V ---+----+----+----+----+
             |    |    |    |    |
            100  100  100  100  100  (ohm resistors)
             |    |    |    |    |

RELAY MODULE WIRING (10-Channel Relay Module)
=============================================
Need 10 relays: 8 for solenoids + 2 for pumps
Relay modules are typically ACTIVE LOW (signal LOW = relay ON)

ESP32-S3                  Relay Module
--------                  ------------
  VIN (5V) ------------->  VCC
  GND ------------------->  GND
  GPIO6  ---------------->  IN1  (Front Left INFLATE)
  GPIO7  ---------------->  IN2  (Front Left DEFLATE)
  GPIO15 ---------------->  IN3  (Front Right INFLATE)
  GPIO16 ---------------->  IN4  (Front Right DEFLATE)
  GPIO17 ---------------->  IN5  (Rear Left INFLATE)
  GPIO18 ---------------->  IN6  (Rear Left DEFLATE)
  GPIO8  ---------------->  IN7  (Rear Right INFLATE)
  GPIO21 ---------------->  IN8  (Rear Right DEFLATE)
  GPIO47 ---------------->  IN9  (Compressor Pump 1)
  GPIO48 ---------------->  IN10 (Compressor Pump 2)


RIDETECH BIG RED MANIFOLD WIRING
================================
The Big Red 4-way manifold has 8 solenoid coils (2 per corner)

Manifold Layout (top view):
+-----------------------------------------------------------------------------------+
|  [FL INF]  [FL DEF]  [FR INF]  [FR DEF]  [RL INF]  [RL DEF]  [RR INF]  [RR DEF]  |
|  GPIO6     GPIO7     GPIO15    GPIO16    GPIO17    GPIO18    GPIO8     GPIO21    |
+-----------------------------------------------------------------------------------+
|   SUPPLY (from tank)              |              EXHAUST (to atmosphere)           |
+-----------------------------------------------------------------------------------+
|        FL DELIVERY    FR DELIVERY    RL DELIVERY    RR DELIVERY                    |
|         (to bag)       (to bag)       (to bag)       (to bag)                      |
+-----------------------------------------------------------------------------------+

Port Connections:
- SUPPLY ports (2x 1/4"): Connect to air tank
- EXHAUST ports (2x 1/4"): Open to atmosphere (add mufflers for quiet operation)
- DELIVERY ports (4x 1/4"): Connect to each air bag
- GAUGE ports (4x 1/8"): Connect to VDO pressure sensors


SOLENOID WIRING DETAIL (x8 solenoids)
=====================================
RideTech Big Red solenoids are 12V, normally closed

    +12V (Fused)
        |
    [Relay NO]----+
        |         |
        +---------|<|------+   <-- 1N4007 flyback diode
        |                  |       (cathode to +12V side)
   [Solenoid +]      [Solenoid -]
        |                  |
        +------------------+
                |
               GND

    Each solenoid coil: ~3-5 ohms, draws ~2-4A when energized
    Use relays rated for at least 5A per channel


COMPRESSOR PUMP WIRING (12V pumps x2)
=====================================
Higher current than solenoids - use appropriate relay rating

    +12V (Fused - 20A per pump)
        |
    [Relay NO]----+
        |         |
        +---------|<|------+   <-- 1N4007 flyback diode
        |                  |
   [Pump Motor +]    [Pump Motor -]
        |                  |
        +------------------+
                |
               GND

    Add 100uF capacitor near each pump for noise suppression

WIRING COLOR CODE SUGGESTION
============================
- RED: +12V power
- BLACK: Ground
- ORANGE: Inflate solenoid signals
- BLUE: Deflate solenoid signals
- GREEN: Pump signals
- YELLOW: Sensor signals
- WHITE: 5V/3.3V power


ESP32-S3 ADVANTAGES
===================
1. Built-in WiFi - no shield needed, smaller package
2. Faster processor (240 MHz dual-core vs 16 MHz)
3. More memory (512KB SRAM + 8MB PSRAM option vs 8KB)
4. 12-bit ADC (4096 levels vs 1024)
5. Lower cost than Mega + WiFi Shield
6. OTA (Over-The-Air) update capability
7. Bluetooth 5.0 (LE) available if needed later
8. Native USB support - no FTDI/CP2102 chip needed
9. More GPIO pins available than original ESP32


NOTES
=====
1. CRITICAL: Use ADC1 pins only (GPIO 1-10) - ADC2 conflicts with WiFi!
2. ESP32-S3 operates at 3.3V logic - use 3.3V for voltage dividers
3. Use LM2596 buck converter, not 7805 (cleaner power, higher efficiency)
4. All grounds must be connected together (common ground)
5. Keep sensor wires away from relay/solenoid wires to reduce noise
6. Use shielded cable for sensor wires if experiencing interference
7. RideTech Big Red solenoids use Weatherpak connectors
8. Test relay module polarity - some are active HIGH
9. GPIO 0 is boot button - avoid for relays or I/O
10. GPIO 19/20 are reserved for USB D-/D+ (native USB) - do not use
11. ADC1: GPIO 1-10 (safe with WiFi), ADC2: GPIO 11-20 (avoid with WiFi)
